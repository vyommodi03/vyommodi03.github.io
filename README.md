Welcome to the source code for my interactive, command-line interface (CLI) style portfolio. 

As a **Lead Product Engineer** specializing in ** Backend Architecture**, I wanted a personal website that reflects the environment where I spend most of my time: the terminal. This project transforms a standard static resume into a fully interactive web application, simulating a native OS terminal experience entirely within the browser.

> 🚀 **[Launch the Terminal Experience](https://vyommodi03.github.io/)**

---

## ⚡ Features

This isn't just a block of text styled to look like a console; it's a functioning terminal emulator built from scratch in vanilla JavaScript.

*   **Custom Boot Sequence:** Simulates a system BIOS boot and hardware check on load.
*   **Virtual File System:** Use commands like `ls` and `cat` to navigate and read my resume sections (e.g., `cat experience.txt`).
*   **Command History:** Navigate previously entered commands using the `Up` and `Down` arrow keys, just like a real bash shell.
*   **Tab Autocomplete:** Type partial commands or filenames and press `Tab` to autocomplete.
*   **Draggable GUI Window:** The terminal is wrapped in a macOS-style window that can be clicked and dragged around the viewport.
*   **Interactive Theming:** Switch the aesthetic dynamically using the `theme` command (e.g., `theme hacker`, `theme ubuntu`, `theme light`).
*   **Mini-Games & Easter Eggs:** Fully playable offline mini-games and hidden commands (`snake`, `guess`, `rickroll`, `matrix`).
*   **Zero Dependencies:** Built entirely with vanilla HTML, CSS, and JavaScript. No heavy frameworks or external libraries required.

## 🛠️ Commands to Try

Once you launch the terminal, try running these commands:

| Command | Description |
| :--- | :--- |
| `help` | Displays the list of available commands. |
| `about` | Prints a brief introduction. |
| `experience` | Outputs my professional work history. |
| `skills` | Lists my technical proficiencies (AI, Backend, etc.). |
| `clear` | Clears the terminal output. |
| `theme <name>`| Changes the terminal UI (try: `mac`, `ubuntu`, `hacker`, `windows`). |
| `matrix` | Triggers a digital rain background effect. |
| `snake` | Launches a playable game of Snake in the console. |
